# V4-RC1 验收测试

## Test 1：华数杯微构体三维图

要求：

- 完整立方体研究域；
- 原点在透视深处的三棱交点；
- xyz 明确并延伸超出研究域；
- L=10000 nm；
- A 圆柱长 5000 nm，视觉轴长约 L/2；
- 纯黑白；
- 无灰色填充；
- 无解释框；
- 一张图只画三维；
- 图下方单独提供：
  `图 X 微构体内 A–A 最近距离的三维几何关系`
