# 最终验收清单（V4-RC2 develop）

## 建模
- [ ] 第一问是可复用基础模型
- [ ] 后续问题明确继承前问
- [ ] 有结构证明
- [ ] 算法由结构决定
- [ ] 有独立验证
- [ ] 最后一问先降维再优化

## 绘图：核心信息
- [ ] 能否用一句话说清“这张图只需要让读者看懂什么”
- [ ] 这张图是否只有一个核心信息
- [ ] 是否把信息分成“必须展示 / 可以弱化 / 应当删除”
- [ ] 是否删除了与核心信息无直接贡献的连线、箭头、轨迹和尺寸
- [ ] 是否避免 all-to-all 关系线
- [ ] 每个箭头是否都有唯一且不重复的语义
- [ ] 辅助线是否没有压过核心对象
- [ ] 读者是否能在 3–5 秒内识别主角、位置和核心关系

## 绘图：全局与局部
- [ ] 全局图是否只负责“谁在哪里 / 整体结构是什么”
- [ ] 局部几何、判据或轨迹是否在需要时另画并放大
- [ ] 两张图如需并排，是否仍保持为两个独立图文件
- [ ] 三维图是否增加了二维图没有的真实空间信息
- [ ] 二维图是否主要承担局部算法、投影和数学判据

## 绘图：论文视觉规范
- [ ] 一图一文件
- [ ] 默认不拼图
- [ ] 纯黑白为主
- [ ] 无灰色装饰性填充
- [ ] 无解释框
- [ ] 图内文字最少
- [ ] 图注独立在下方
- [ ] 坐标系原点主动设计
- [ ] xyz 清楚
- [ ] 宏观尺寸真实
- [ ] 变量与公式一致
- [ ] 缩入论文后可读
- [ ] 定量图来自真实模型数据

## 一票否决

出现以下任一情况，不进入最终论文：

- 核心信息说不清；
- 一个图同时承担“空间配置 + 运动过程 + 几何判据”；
- 箭头、虚线和辅助关系比对象本身更醒目；
- 为了“信息完整”而绘制所有候选连接；
- 删除约三成辅助线后反而更清楚；
- 读者必须逐条追踪连线才能理解图意。
