# 坐标系选择规则

坐标系的目标不是“标准”，而是让后续数学关系更简单、更清楚。

## 1. 规则盒体

优先考虑：

\[
\Omega=[0,L_x]\times[0,L_y]\times[0,L_z].
\]

图形表达中，原点优先置于透视上较深的三棱交点。

轴沿三条棱建立，并适当超出研究域。

## 2. 中心对称

球、圆盘、中心源、旋转系统：

优先几何中心为原点。

## 3. 运动问题

让一个坐标轴与主运动方向或初始切线一致。

## 4. 光学问题

让主传播方向成为优先轴；法线/切向方向与公式一致。

## 5. 坐标系最终检查

- 公式是否更短？
- 边界条件是否更自然？
- 图上是否一眼看懂？
- 是否和程序坐标一致？
- 若不一致，是否明确给出平移/旋转变换？
