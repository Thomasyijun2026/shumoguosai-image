# 多图生成与论文排版规则

> 本规则用于区分“生成阶段”和“论文排版阶段”。

# 1. 核心规则

如果需要表示两种或多种情况，可以在最终论文中并排或上下组合，但**生成时必须分别生成独立图片文件**。

固定流程：

```text
情况 A → 独立生成 figure_A.png / .svg
情况 B → 独立生成 figure_B.png / .svg
情况 C → 独立生成 figure_C.png / .svg

                ↓

Word / LaTeX / WPS 排版阶段再组合
```

因此：

\[
\boxed{\text{允许排版拼接，不允许生成阶段烘焙拼图}}
\]

---

# 2. 交付规则

如果论文最终需要两个子图，例如：

```text
(a) 全局空间位置
(b) 局部几何关系
```

助手交付给用户的必须是：

```text
figure_global.png
figure_local.png
```

而不是：

```text
figure_ab_combined.png
```

除非用户明确要求“现在直接帮我排成最终论文版式”。

---

# 3. 为什么必须分开生成

独立生成可以保证：

1. 每张图只有一个核心信息；
2. 每张图可以单独调整视角、比例和裁切；
3. 论文排版时可以自由改变两图大小比例；
4. 可以单独替换其中一张，不必重做整张拼图；
5. 图中文字尺寸不会因为整体拼接而缩得过小；
6. 可以根据页面空间选择并排、上下或跨页；
7. 更符合论文图的制作流程。

---

# 4. 什么时候适合最终并排

以下情况可以在论文排版阶段并排：

- 全局图 + 局部放大图；
- 三维空间图 + 二维分析图；
- 情况 A + 情况 B 对照；
- 优化前 + 优化后；
- 方法 1 + 方法 2；
- 不同参数条件下的同类结果图。

但它们仍然必须先作为独立图片完成并分别验收。

---

# 5. 排版阶段的组合方式

例如最终论文需要：

```text
┌──────────────┬──────────────┐
│  figure_A    │  figure_B    │
└──────────────┴──────────────┘
        图 X 两种情况对比
```

这是**Word/LaTeX/WPS 的排版行为**，不是绘图模型的生成行为。

---

# 6. 每张独立图仍需满足原有规则

每一张图都必须单独通过：

- 一个核心信息；
- 纯黑白默认风格；
- 无多余解释框；
- 图内文字最小化；
- 坐标系与尺寸正确；
- 3–5 秒识别测试；
- 独立图注可单独成立。

---

# 7. 助手行为约束

当用户说：

> “做两种情况对比”

默认执行：

```text
先分别生成两张图
→ 分别交付给用户检查
→ 用户确认后
→ 如有需要，再提供论文排版建议或组合版式
```

不得自行把两张图直接合成一张图片交付。

---

# 8. 最终一句话规则

\[
\boxed{
\text{多种情况可以在论文里拼，生成时必须分开。}
}
\]
