# CUMCM2026 Modeling Skills

面向 2026 全国大学生数学建模竞赛的建模、证明、求解、论文结构和绘图技能库。

## 目录

- `SKILL.md`：总技能入口
- `drawing/FIGURE_SKILL.md`：最高优先级绘图规范
- `drawing/COORDINATE_SYSTEM.md`：坐标系选取
- `drawing/CAPTION_STYLE.md`：图内文字与图注
- `modeling/MODELING_LOGIC.md`：问题递进
- `modeling/PROOF_AND_VALIDATION.md`：证明与验证
- `modeling/ALGORITHM_SELECTION.md`：算法选择
- `templates/FIGURE_DESIGN_CARD.md`：绘图设计卡
- `templates/TASK_INSTRUCTION.md`：可复制任务指令
- `templates/PAPER_SECTION_TEMPLATE.md`：论文章节模板
- `tests/TESTS.md`：验收测试
- `tests/ACCEPTANCE_CHECKLIST.md`：最终检查

## 使用顺序

1. 先读 `SKILL.md`
2. 建模前执行 `MODELING_LOGIC`
3. 选择算法前执行 `PROOF_AND_VALIDATION`
4. 每画一张图前执行 `FIGURE_DESIGN_CARD`
5. 每张图输出后执行 `ACCEPTANCE_CHECKLIST`

## 当前版本

`V4-RC1`
